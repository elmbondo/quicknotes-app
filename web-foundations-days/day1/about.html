About QuickNotes

QuickNotes is a small app for writing down quick reminders and ideas. It is made for people who want to save a thought before they forget it.

How to use QuickNotes

  1. Type your note in the text box.
  2. Click the Add Note button or press Enter.
  3. Find your note in the Your notes list.

Features

  • Add a note in a few seconds
  • See how many notes you have
  • Works on both phones and computers

Keyboard shortcuts

Shortcut Action
Enter Add the note
Tab Move to the next field
Ctrl + S Save the file in VS Code
